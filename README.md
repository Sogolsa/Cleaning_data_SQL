# Hotel Bookings Data Cleaning – Project Summary
## What I did:
1. Standardized inconsistent date formats

2. Combined year/month/day into a single ArrivalDate

3. Converted adults/children/babies to numeric

4. Fixed “NA” values and replaced them properly

5. Reformatted is_canceled and created cleaned versions

6. Identified and removed duplicates

7. Dropped outdated/non-usable columns

# **Key Insights After Cleaning**

1. The dataset had duplicates that needed removal.

2. Children column had 4 invalid “NA” values stored as text.

3. Several numeric columns were incorrectly stored as text.

4. Date fields were inconsistent and required conversion before analysis.

**After cleaning, the dataset became fully usable for visualization and revenue analysis.**
